# Prerequisites

OpenShift is installed by generating an ISO that every host in the cluster boots from. As the hosts come up, they coordinate through one host designated as the bootstrap node, and the installation proceeds from there. Because all hosts share the same ISO and require network connectivity, the ISO must carry enough configuration to bring each host onto the network. Alongside that networking information, the installer needs to know, for each host, which disk to install to, the SSH public keys for access, a pull secret for authenticating to the Red Hat Hybrid Cloud Console, and cluster-wide settings such as DNS and NTP server addresses.

## The Full List

### Cluster 

| Item                   | Description                                                         | Example value             |
| ---------------------- | ------------------------------------------------------------------- | ------------------------- |
| Cluster name           | Combined with the base domain for cluster FQDN                      | hub                       |
| Base domain            | DNS domain under which cluster records are created                  | clusters.example.com      |
| Machine network (CIDR) | Subnet the host interfaces reside on                                | 10.0.0.0/24               |
| Cluster network (CIDR) | Internal pod IP range; must not overlap other networks              | 10.128.0.0/14             |
| Service network (CIDR) | Internal service IP range; must not overlap other networks          | 172.30.0.0/16             |
| API VIP                | Virtual IP for the OpenShift API                                    | 10.0.0.10                 |
| Ingress VIP            | Virtual IP for application ingress                                  | 10.0.0.11                 |
| Rendezvous IP          | IP of the host the others coordinate through during install         | 10.0.0.20                 |
| NTP server address(es) | Time sources for host clock synchronization                         | ntp1.example.com          |

### Per-Host

| Item                   | Description                                                         | Example value             |
| ---------------------- | ------------------------------------------------------------------- | ------------------------- |
| Host Name              | Hostname                                                            | dctla-ocpcp1              |
| Role                   | Host role, master or worker                                         | master                    |
| Root Device Hint       | Install disk for OpenShift                                          | /dev/sda                  |
| BMC IP                 | IP address for connecting to host BMC                               | 192.168.1.253             |
| BMC Credentials        | Credentials for connecting to host BMC                              | admin / password          |
| Interfaces             | Interfaces in the bond, identified by nic/MAC                       | enp1s0 - 00:1A:2B:3C:4D:00 |
| Bond name              | Name of the bonded interface                                        | bond0                     |
| Bond mode              | Link aggregation mode for the bond                                  | 802.3ad                   |
| Bond LACP rate         | LACPDU transmit rate for the 802.3ad bond                           | fast                      |
| Bond MII monitor       | Link monitoring interval in milliseconds                            | 100                       |
| VLAN ID                | Tag for the VLAN interface carried over the bond                    | 100                       |
| VLAN base interface    | Underlying interface the VLAN is built on                           | bond0                     |
| Host IP address        | Static IP, assigned to the VLAN interface                           | 10.0.0.20                 |
| Subnet prefix          | Prefix length for the host interface                                | 24                        |
| Default gateway        | Next-hop gateway for each host                                      | 10.0.0.1                  |
| DNS server address(es) | Upstream resolvers                                                  | 9.9.9.9, 149.112.112.112  |
